# Immersive Interaction Prompts

A planned standalone interface mod for **Asterigos: Curse of the Stars**.

Contextual world-object prompts will gain a visually prominent upper line in fitting Aphes-world lettering, with a clearly readable localized interaction action below. A delicate divider is under consideration. The actual action, native input icon and prompt visibility must stay correct.

Examples: pick up, open, read, descend; other context actions only when supported by the verified presentation path.

**Status: research; production gate BLOCKED. No production build or release exists.** A [minimal CanShow observer](research/interaction-prompts-owner/can-show-state/README.md) is installed for its first user-operated test; runtime evidence is pending. It reads current prompt text/state only; native-array observation and UEPseudo investigation are deferred. Live final writer, input texture producer and a usable UMG glyph path remain open. Invented decorative symbols must not be presented as a genuine fictional language.

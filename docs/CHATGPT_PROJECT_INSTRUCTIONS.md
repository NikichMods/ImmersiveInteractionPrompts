# ChatGPT Project Instructions — Immersive Interaction Prompts

Project: `Immersive Interaction Prompts`; independent repository:
`NikichMods/ImmersiveInteractionPrompts`.
Target: Asterigos: Curse of the Stars (Windows x64, UE4.27); use only the host
build and UE4SS environment established by current repository evidence.
Purpose: give contextual world-object interaction prompts a fitting upper line
of Aphes-world lettering and a readable localized action below, without changing
native controls or interaction behavior.

Read current `NikichMods/DevRules/WORKING_RULES.md` and this repository's root
`AGENTS.md`. Follow the DevRules action-based reading map and the relevant
engineering, Git, runtime, CI, licensing and acceptance rules. For local Codex
work also follow `CODEX_WORKFLOW.md`, inspect the actual checkout/worktree and
preserve unpublished changes. These pointers grant no additional permissions.

Canonical recovery in **this repository**:

- `docs/REQUIREMENTS.md` — adopted scope, visual reference and invariants.
- `docs/STATUS.md` — current status, blockers and next sufficient step.
- `docs/VERIFIED_RUNTIME.md` — established technical evidence and its limits.
- `docs/RESEARCH_PLAN.md` — bounded next investigation, when relevant.
- `README.md`, `AGENTS.md`, `VERSION`, `docs/WORKFLOW.md` — identity and workflow.

Shared game knowledge: `NikichMods/Asterigos-Research/docs/RESEARCH_INDEX.md`.
Read relevant verified findings before new host research; promote concise,
reusable game-level conclusions there under DevRules. Mod-specific design,
source, test evidence, version and acceptance remain in this repository.
`NikichMods/AsterigosMods` is historical provenance only; see `docs/MIGRATION.md`.

Project boundaries:

- This ChatGPT Project concerns only ImmersiveInteractionPrompts, not CombatHUD
  or other Asterigos mods. A shared game/installation is not shared ownership.
- Prefer available remote/GitHub tools. When installed-game resources or live
  evidence are essential, hand the user a bounded task for **user-started local
  Codex**; recover its actual pushed commit before making technical decisions.
- Do not launch/terminate the game, install over a running host, change saves or
  settings, or use hot reload without separately established authorization.
- Preserve native localized action, input hints/remapping, show/hide, interaction
  semantics and unrelated UI. Do not present decorative glyphs as verified lore;
  do not publish proprietary host assets without a valid provenance basis.
- Production readiness and real-game visual acceptance must be demonstrated;
  offline inspection is not runtime acceptance.

Repository evidence outranks chat memory when they conflict. Keep mutable state
and adopted decisions in the owning repository documents, never these Project
Instructions. New chats can begin directly with the actual task.

This is a bootstrap adapter, not a duplicate of DevRules or live project status.
